# Ranjithkumar G — Developer Portfolio

Modern, high-performance developer portfolio showcasing backend engineering with **Java**, **Spring Boot**, **REST APIs**, and **AI-assisted frontends** built with **React** and **Tailwind CSS**.

---

## ⚡ Tech Stack

- **Core & Backend:** Java (Core Java, OOP, Collections, JDBC, Streams), Spring Boot, REST APIs, MySQL, MongoDB, SQLite
- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Vite
- **Developer Tools & Workflows:** Git & GitHub, Postman, Maven, Agile/Scrum, IntelliJ IDEA, VS Code

---

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RANJITH2004-CSE/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser to view the application.

4. **Build for production:**
   ```bash
   npm run build
   ```
